## 🚀 How to Use This Repo

### Creating a New Issue

1. **Click "New Issue"** → Choose a template:
   - **Roadmap Item** — Quarterly milestone
   - **Learning Goal** — Training objective
   - **Tool Building** — Development task
   - **Research Task** — Investigation
   - **Writeup** — Documentation

2. **Fill in required fields:**
   - **Title:** Clear, specific description
   - **Description:** Context, acceptance criteria, deliverables
   - **Track Label:** Select your track
   - **Type Label:** Choose type
   - **Status Label:** Start with `status:planning`
   - **Priority Label:** Select priority
   - **Milestone:** Q3 2026, etc. (optional)
   - **Assignee:** Yourself

3. **Click "Create issue"**

### Updating Issue Status

1. **Start work:** Change label to `status:in-progress`
2. **Hit blocker:** Change label to `status:blocked`, add comment
3. **Ready for review:** Change label to `status:review`
4. **Finished:** Change label to `status:complete`, close issue

### Linking Issues

Reference other issues or PRs:
```markdown
Blockers: #5, #12
Depends on: #3
Related to: queen-sheba-protocol/Sheba-protocol-Organization-Hub#2
```
